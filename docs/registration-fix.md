# תיקון הרשמה: הצטרפות שנשמרת בשרת

## מה הייתה התקלה
אחרי אימות הזהות (שם + תז) התלמידה פתחה חשבון וקיבלה מייל אימות. קישור האימות נפתח בדפדפן/מכשיר אחר מזה שבו אימתה את הזהות (למשל מוואטסאפ לדפדפן ברירת המחדל). האימות נשמר רק בלשונית הראשונה, ולכן הלשונית השנייה ביקשה שוב שם ותז. בנתוני הייצור רואים שהצטרפות הושלמה בלשונית הראשונה 77 שניות אחרי האימות, ולכן הניסיון השני נדחה כי השם כבר נרשם.

## התיקון (מיגרציה 4 + ממשק)
- מיד אחרי אימות הזהות, ולפני פתיחת החשבון, השרת קושר את האימות (חד־פעמי, בתוקף 3 ימים) לכתובת האימייל שהוקלדה. האימייל נשמר כ־HMAC בלבד.
- אחרי אימות האימייל, בכל מכשיר ובכל דפדפן, התלמיד נכנס והממשק קורא ל־`complete_pending_join`. השרת משלים את השיוך לרשומה שאומתה, שומר את הזהות ומצרף לכיתה. התלמיד מועבר למסך הבית בלי לשאול שוב שם או תז.
- פתיחה חוזרת של הקישור על ידי תלמיד שכבר בכיתה מעבירה אותו הביתה, בלי כפילויות, גם אם הקישור פג בינתיים.
- חשבון שנוצר לפני התיקון ולא השלים הצטרפות לא נמחק: הוא נכנס, בוחר שם ומקליד תז פעם אחת, ומצטרף.
- אי אפשר לעקוף את אימות הזהות: אימות נוצר רק אחרי תז נכונה, הוא קשור לאימייל אחד, חד־פעמי, פג תוקף, ובטל אם הקישור בוטל או פג.

## פריסה
1. הריצו `20261118000400_pending_join.sql` ב־SQL Editor (דורש את מיגרציה 3).
2. העלו את קבצי הקוד מה־ZIP.

## מיתוג אימייל "חוליה" -> "הבנתי" (ידני בדשבורד, לא ניתן ב־SQL או בקוד)
בקוד אין עוד טקסט מיתוגי ישן ("חוליה" מופיע רק כמונח לימודי). תבניות האימייל נמצאות בהגדרות Supabase:
1. Authentication -> Emails -> Templates -> **Confirm signup**:
   - Subject: `אימות כתובת האימייל שלך ב״הבנתי״`
   - Body (HTML):
     ```html
     <div dir="rtl" style="font-family:Arial,sans-serif;font-size:16px;line-height:1.6">
       <h2>הבנתי</h2>
       <p>כדי להשלים את ההצטרפות לכיתה, אמתו את כתובת האימייל:</p>
       <p><a href="{{ .ConfirmationURL }}">אימות האימייל</a></p>
       <p>אם לא ביקשתם להירשם, אפשר להתעלם מהמייל.</p>
     </div>
     ```
2. אותו דבר ב־**Invite user**, **Reset password**, **Magic link**, **Change email address**: להחליף כל "חוליה" ב־"הבנתי".
3. Authentication -> URL Configuration: **Site URL** = כתובת האתר הסופית (לא localhost); ב־Redirect URLs: `https://<הדומיין>/join/**` ו־`https://<הדומיין>/set-password`.
4. שם השולח: בשליחה מובנית של Supabase השולח הוא "Supabase Auth" ואי אפשר לשנותו. כדי שיופיע "הבנתי" צריך SMTP מותאם: Authentication -> Emails -> SMTP Settings, Sender name = `הבנתי`. השליחה המובנית גם מוגבלת לכמה מיילים בשעה, ולכן מומלץ SMTP מותאם לפני הצטרפות כיתה שלמה.
5. Project Settings -> General: שם הפרויקט (פנימי, לא חובה).
לא היה לי גישה לקרוא את ההגדרות האלה, ולכן לא אימתתי מה כתוב בהן כעת.
