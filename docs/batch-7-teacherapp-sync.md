# מנה 7: סנכרון כיתות מ־TeacherApp

## מה נבנה
- **קריאה בלבד** מהסכמה `teacherapp` (אותו פרויקט Supabase). שום כתיבה ל־TeacherApp, בלי API ובלי טריגרים אצלה.
- **כל קבוצה ב־TeacherApp = כיתה אחת בהבנתי.** קישור יוצר כיתה חדשה (בשם הקבוצה) או מתחבר לכיתה קיימת במקצוע.
- **תצוגה מקדימה לפני אישור:** חדש / כבר ברשימה (חיבור) / עזב / שם שונה / שם כפול. כלום לא משתנה עד לחיצה על "אישור".
- **שינוי ב־TeacherApp:** מופיעה הודעה אוטומטית בבית המורה ובעמוד "כיתות", ובכיתה עצמה יש רשימת שינויים. תלמיד שעזב: ברירת מחדל "להשאיר מחובר", ואפשר "להסיר מהכיתה".
- **הסרה** מוציאה את התלמיד מהכיתה בלבד. החשבון, ההרשמה למקצוע וההתקדמות נשמרים.
- **ת״ז:** TeacherApp לא שומרת ת״ז, ולכן תלמיד מסונכרן מגיע לרשימה בלי ת״ז ("ממתין לת״ז") ואינו מופיע לתלמידים עד שמדביקים או מעלים את הרשימה עם ת״ז. השם נתאים לשורה הקיימת ומשלים לה את הת״ז (בלי כפילות). בדיקת הזהות בהצטרפות לא השתנתה.
- **הרשאות:** רק מורה שהמייל המאומת שלו הוא הבעלים ב־`teacherapp.owner_config` ושהכיתה שלו. לכל אחד אחר הכול מוסתר.

## פריסה (מהסדר הנכון)
1. **Supabase, SQL Editor:** להריץ את `supabase/migrations/20261119000100_teacherapp_sync.sql` (הדבקה של כל הקובץ, Run). המיגרציה דורשת ש־20261118000400 כבר הורצה (הורצה) ושהסכמה `teacherapp` קיימת (קיימת).
2. **GitHub:** להעלות את קבצי ה־ZIP בנתיבים המקוריים ולחכות ל־Vercel.
3. לא נדרש שינוי בהגדרות Supabase או ב־TeacherApp.

## בדיקה ראשונה (5 דקות)
1. עמוד קורס, "כיתות": תופיע שורה עם בחירת קבוצה מ־TeacherApp. לבחור קבוצה ו"כיתה חדשה", "קישור וסנכרון".
2. בכיתה החדשה מופיעה תצוגה מקדימה. "אישור" מוסיף את התלמידים (בלי ת״ז).
3. להדביק או להעלות את הרשימה מהאקסל של משו״ב בלוח "רשימת תלמידים בכיתה": ההודעה "עודכנו ת״ז" מראה שהשורות התמלאו.
4. ב־TeacherApp להוסיף תלמיד או לסמן עזיבה ולחזור להבנתי: תופיע הודעה בבית המורה.

## מה לא נבדק
- לא נבדק בדפדפן אמיתי מול Supabase אמיתי, רק בבדיקות אוטומטיות (ממשק) וב־Postgres מקומי עם סכמת TeacherApp מדומה (עמודות אומתו מול הייצור).
- ההודעה נבדקת בעת פתיחת המסך (לא נדחפת בזמן אמת).

## מגבלות
- שם כפול (שני תלמידים באותו שם) מסומן "לטפל ידנית" ואינו מחובר אוטומטית.
- ההתאמה לפי שם (שם משפחה + שם פרטי). שינוי כתיב ב־TeacherApp יוצג כ"שם שונה" אם התלמיד כבר מחובר, או כ"חדש" אם לא.
