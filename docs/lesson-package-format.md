# מבנה חבילת שיעורון ("הבנתי")

שיעורון הוא הרצאה אינטראקטיבית אחת, עצמאית. אין בו שאלות תרגול ואין צ'אט, ואין שירותים חיצוניים.

## קבצים מותרים
- **קובץ HTML בודד**: הכול בתוכו (CSS ו-JS מוטמעים, תמונות כ-`data:`).
- **ZIP**: `index.html` (או קובץ HTML יחיד בשורש) + קבצי CSS, JS, תמונות (png/jpg/gif/webp/svg), גופנים (woff/woff2/ttf/otf) ואודיו/וידאו מקומי. תיקייה עוטפת אחת מותרת.
- מגבלות: קובץ עד 10MB, עד 400 קבצים, 30MB אחרי פתיחה, 6MB אחרי איחוד.
- אסור: משאבים חיצוניים (`http(s)://`, CDN, גופנים מרוחקים), `import` של מודולים, `<base>`, `<meta refresh>`, iframe/object/embed/form. קישורים החוצה מוסרים; קישורי עוגן `#id` נשמרים.

בעת ההעלאה כל הקבצים מאוחדים לדף אחד נקי (הקבצים המקומיים מוטמעים), ומחושב לו גיבוב SHA-256.

## מניפסט (אופציונלי, מומלץ)
ב-ZIP: קובץ `hevanti.json` בשורש. ב-HTML בודד: `<script type="application/json" id="hevanti-manifest">…</script>` (מוסר מהתוצר).

```json
{
  "format": 1,
  "lessonId": "triangle-angle-sum",
  "title": "סכום הזוויות במשולש",
  "subject": "מתמטיקה",
  "grade": "ז",
  "level": "בסיסי",
  "topicIds": ["<uuid>"],
  "topicPaths": [["גאומטריה", "משולשים", "סכום זוויות"]],
  "treeVersion": "2026-11",
  "contentVersion": "1.0"
}
```

- `lessonId` הוא המזהה היציב של השיעורון (3–80 תווים, בלי רווחים). העלאה חוזרת עם אותו `lessonId` יוצרת **גרסה חדשה** של אותו שיעורון, והשיוך לנושאים הקיים נשמר. בלי `lessonId` המזהה נגזר מהכותרת (עם אזהרה).
- שיוך לנושאים לפי הסדר: (1) `topicIds`; (2) `subject` + `topicPaths` בשמות מדויקים (אחרי נרמול ניקוד, מירכאות ורווחים); (3) ידני. עמימות או אי-התאמה תמיד מובילות לשיוך ידני, אף פעם לא לניחוש.
- שיוך הוא בדיוק לנושאים שסומנו, בכל רמה. אין הרחבה אוטומטית לנושאים שמעליהם או מתחתיהם.

## ממשק לשיעורון (`window.Hevanti`)
| API | תיאור |
|---|---|
| `Hevanti.progress.get()` | מחזיר את ההתקדמות השמורה (או `null`). |
| `Hevanti.progress.set(obj)` | שומר התקדמות (JSON, עד 64KB). נשמר **מקומית במכשיר**, לפי משתמש + שיעורון + גרסה מפורסמת. גרסה חדשה מתחילה נקי. |
| `Hevanti.scrollTo(elOrY)` | גולל את הדף של "הבנתי" אל אלמנט או מיקום. |
| `Hevanti.viewportHeight()` | הגובה הנראה. |

- בעיצוב: אל תשתמשו ב-`100vh`. השתמשו ב-`var(--hv-vh)` (מתעדכן לפי גובה המסך). הדף של השיעורון גדל לפי התוכן ואין לו גלילה פנימית: הגלילה היא של "הבנתי".
- אין גישה ל-`localStorage`, עוגיות, רשת (`fetch`/XHR/WebSocket), חלון האב או ניווט החוצה.

## בידוד
השיעורון רץ ב-`<iframe sandbox="allow-scripts">` (ללא `allow-same-origin`, כלומר origin ריק), עם מדיניות CSP קפדנית שמוזרקת ראשונה: `default-src 'none'`, סקריפטים וסגנונות מוטמעים בלבד, תמונות/גופנים/מדיה רק `data:`/`blob:`, `connect-src 'none'`, בלי frames/objects/forms. תקשורת עם המעטפת רק דרך `postMessage` עם אסימון אקראי, ורק הודעות height/progress/scroll מאומתות.

הערה: אם בעתיד תתווסף מדיניות CSP גלובלית לאתר (`vercel.json` או `index.html`), מסמכי `srcdoc` עלולים לרשת אותה. כרגע אין כזו.

## מחזור חיים
העלאה → טיוטה → תצוגה מקדימה → פרסום. שחזור גרסה קודמת יוצר גרסה **חדשה** עם התוכן הישן ומפרסם אותה (ההיסטוריה לא נמחקת). אין מחיקה: שיעורון מועבר לארכיון. תלמיד רואה שיעורון רק אם הוא מפורסם **וגם** נושא משויך (או הנושא הראשי שלו) מסומן "לומדים עכשיו" או "נלמד" בכיתה שלו, או שנפתחה גישה מוקדמת לכיתה.
